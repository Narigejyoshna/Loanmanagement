# 🏦 Loan Management System (Java)

A console-based Java application designed to calculate and display monthly EMI (Equated Monthly Installment) breakdowns for various types of loans. The system includes built-in validation for age and tenure based on specific loan categories.

## ✨ Key Features
* **Automated EMI Calculation:** Uses the standard formula: $EMI = \frac{P \cdot r \cdot (1 + r)^n}{(1 + r)^n - 1}$
* **Loan Categorization:** Supports Education, Personal, Gold, Agricultural, and General loans with pre-set interest rates.
* **Smart Validation:** * Restricts applicants to those under 60 years of age.
  * Enforces maximum tenure limits (e.g., 15 years for Education, 3 years for Gold).
* **Detailed Amortization Schedule:** Generates a month-by-month breakdown showing interest paid, principal paid, and the remaining balance.

## 🛠 Technical Implementation
* **Language:** Java
* **Concepts:** Object-Oriented Programming (OOP), Data Encapsulation, Exception Handling (Try-Catch for input validation).
* **Tools:** Java Math Library, Scanner Class.
